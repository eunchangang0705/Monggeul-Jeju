# 몽글제주

제주 오메기떡을 중심으로 기획한 카페 브랜드 웹사이트입니다.
HTML, CSS, JavaScript로 만들었으며 별도의 빌드나 패키지 설치 없이 실행할 수 있습니다.

## 실행 방법

1. ZIP 파일을 압축 해제합니다.
2. `몽글제주/dist/index.html`을 브라우저로 엽니다.
3. 상단 메뉴에서 메뉴 페이지와 몽글한 이야기 페이지로 이동할 수 있습니다.

로컬 서버를 사용하려면 터미널에서 `dist` 폴더로 이동한 후 실행합니다.

```bash
python -m http.server 8000
```

macOS에서는 `python3 -m http.server 8000`을 사용할 수 있습니다.
브라우저에서 http://localhost:8000 을 엽니다.

## 파일 구성

- `dist/index.html`: 메인 페이지
- `dist/menu.html`: 메뉴 페이지
- `dist/story.html`: 몽글한 이야기 페이지
- `dist/style.css`: 공통 디자인과 반응형 스타일
- `dist/script.js`: 메인 페이지 동작
- `dist/menu.js`: 메뉴 분류와 상세 설명 팝업
- `dist/story.js`: 이야기 페이지 내비게이션
- `dist/assets/`: 로고, 캐릭터, 메뉴 사진, 상세페이지 이미지

## 수정 방법

문구와 이미지 경로는 해당 HTML에서, 디자인은 `style.css`에서 수정합니다.
메뉴 상세 팝업 내용은 `menu.js`에서 수정합니다.
사진을 교체할 때는 `assets`에 새 파일을 넣고 HTML의 이미지 경로도 맞춰 주세요.
이야기 상세 이미지 3장은 `story-detail-1.webp`부터 `story-detail-3.webp`까지 순서대로 표시됩니다.

## 현재 구성

말차색과 Pretendard 글꼴을 사용합니다. 메뉴에는 오메기 디저트, 커피, 논커피, 티와 에이드가 있습니다.
몽글한 이야기에는 소개 배너와 세로 상세 이미지 3장이 포함되어 있습니다.
방문 안내에 입력된 주소는 제주특별자치도 제주시 애월읍 광령2길 43-1이며 영업시간은 10:00~18:00입니다.
